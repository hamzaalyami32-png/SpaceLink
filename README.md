🚀 SpaceLink


Space Communication Network Simulator


SpaceLink is an interactive web-based platform developed for the Network Simulation and Modeling (CN453) course.


🌍 Project Idea


The project simulates data transmission between Earth, Mars, and satellite relay nodes.


🎯 The Problem


Space communication faces challenges such as long delays and connection interruptions, which can prevent successful data delivery.


💡 Our Solution


SpaceLink allows users to simulate communication scenarios and compare two transmission strategies:




Direct Transmission: Messages are sent when the connection is available.


Store and Forward: Messages are stored temporarily and transmitted when a connection becomes available.




📊 Project Objectives




Simulate space communication networks.


Study delays and connection interruptions.


Compare data delivery strategies.


Visualize and analyze simulation results.




🛰️ Inspiration


Our project was inspired by the Deep Space Network Simulator (DSNS), a research project associated with the University of Oxford.

🚀 SpaceLink – سبيس لينك


محاكي شبكات الاتصالات الفضائية


SpaceLink هو منصة إلكترونية تفاعلية تم تطويرها ضمن مشروع مقرر محاكاة ونمذجة الشبكات (CN453).


🌍 فكرة المشروع


يقوم المشروع بمحاكاة عملية نقل البيانات بين الأرض والمريخ والأقمار الصناعية التي تعمل كمحطات وسيطة للاتصال.


🎯 المشكلة


تواجه الاتصالات الفضائية عدة تحديات، مثل التأخير الطويل في وصول البيانات والانقطاع المتكرر للاتصال، مما قد يؤدي إلى عدم وصول الرسائل والبيانات بنجاح.


💡 الحل الذي نقدمه


يتيح موقع SpaceLink للمستخدمين محاكاة سيناريوهات مختلفة للاتصالات الفضائية، والمقارنة بين استراتيجيتين لنقل البيانات:




الإرسال المباشر (Direct Transmission): يتم إرسال الرسائل عندما يكون الاتصال متاحًا.


التخزين ثم الإرسال (Store and Forward): تُخزَّن الرسائل مؤقتًا، ثم تُرسل عند توفر الاتصال مرة أخرى.




📊 أهداف المشروع




محاكاة شبكات الاتصالات الفضائية.


دراسة تأثير التأخير وانقطاع الاتصال على نقل البيانات.


مقارنة استراتيجيات إرسال البيانات المختلفة.


عرض نتائج المحاكاة وتحليلها باستخدام الرسومات البيانية والمؤشرات.




🛰️ مصدر الإلهام


استوحينا فكرة مشروعنا من محاكي شبكات الفضاء العميق (Deep Space Network Simulator – DSNS)، وهو مشروع بحثي مرتبط بجامعة أكسفورد البريطانية.


ومن خلال هذا الإلهام، قمنا بتطوير منصة SpaceLink بأسلوب مبسط وتفاعلي يركز على دراسة مشكلة انقطاع الاتصال وتأثيرها على وصول البيانات في الشبكات الفضائية.
