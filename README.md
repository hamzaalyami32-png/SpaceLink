🚀 SpaceLink


Space Communication Network Simulator


SpaceLink is an interactive web-based platform developed for the Network Simulation and Modeling (CN453) course.


🌍 Project Idea


The project simulates data transmission between Earth, Mars, and satellite relay nodes.


🎯 The Problem


Space communication faces challenges such as long delays and connection interruptions, which can prevent successful data delivery.


💡 Our Solution


SpaceLink allows users to simulate communication scenarios and compare two transmission strategies:




Direct Transmission: Messages are sent when the connection is available.


Store and Forward: Messages are stored temporarily and transmitted when a connection becomes available.




📊 Project Objectives




Simulate space communication networks.


Study delays and connection interruptions.


Compare data delivery strategies.


Visualize and analyze simulation results.




🛰️ Inspiration


Our project was inspired by the Deep Space Network Simulator (DSNS), a research project associated with the University of Oxford.
